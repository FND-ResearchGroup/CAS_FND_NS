# HEP in FND

 date: 		17 September 2025
 author: 	Natascha Stoffel, natascha.stoffel@unifr.ch
 
This git hub repository entails the data, scripts and output for the project "Altered Predictive Coding in Functional Neurological Disorders" - Stoffel et al., aimed to be submitted to the Special Edition of Psychophysiology (Bridging Neural and Bodily Signals: Techniques, Methods, and Theoretical Advancements)

This repository will be structured as follows (please note that the data and code will be made available once the manuscript is published)


#### Code :		
-  R analysis markdown :  R script (quarto document/html file)
-  output : output generated via Rscript


#### Data :		
-  Data Dictionary
-  excel file with CRF data from those people who gave consent on further use of the data


#### Publication :
-  publication derived from these data and analysis
