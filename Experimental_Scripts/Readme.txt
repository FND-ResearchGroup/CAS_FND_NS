Two folders: 
- 'Experimental_script_EPRIME': It contains the Eprime3 script with the task instructions, as well the managing the black screen during the recording. 
- 'Experimental_script_LABVIEW': The script used during the task simultaneously managed the presentation of auditory stimuli in synchronous or asynchronous mode with the heartbeat, as well as the EEG/ECG recording.
